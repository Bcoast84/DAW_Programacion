## 📌 Contenidos del Repositorio

El código está organizado por trimestres y tareas temáticas, abarcando desde los fundamentos de la sintaxis en Java hasta estructuras algorítmicas avanzadas:

### 📁 Primer Trimestre (`Trimestre1/`)

* **`tarea1/` — Fundamentos y Entrada/Salida básica (Ejercicios 1.01 al 1.10)**
  * Primeros pasos con Java y entorno de desarrollo.
  * Tipos de datos primitivos (`int`, `double`, `boolean`, `char`).
  * Entrada de datos por consola con `java.util.Scanner`.
  * Operadores aritméticos, asignaciones y formateo de texto (`System.out.println`).

* **`tarea2/` — Estructuras Condicionales y Selectivas (Ejercicios 2.00 al 2.25)**
  * Bifurcaciones simples y compuestas: `if`, `if-else` y `else if`.
  * Operadores relacionales (`==`, `!=`, `<`, `>`, `<=`, `>=`) y lógicos (`&&`, `||`, `!`).
  * Estructura selectiva múltiple: `switch - case`.
  * Algoritmos de ordenación simple, clasificación y control de flujo.

* **`tarea3_1a/` — Estructuras Repetitivas I (Ejercicios 1.01 al 1.15)**
  * Introducción a bucles fundamentales: `while`, `do-while` y `for`.
  * Implementación de contadores, acumuladores e iteradores.
  * Cálculo de números primos, divisores, múltiplos y números perfectos.
  * Detección de patrones y series numéricas.

* **`tarea3_b/` — Estructuras Repetitivas II y Algoritmia Avanzada (Ejercicios 1.01 al 1.14)**
  * Validación estricta de entradas por teclado mediante bucles `do-while`.
  * Bucles dependientes de valores centinela o condiciones de salida.
  * Cálculo de máximos, mínimos y promedios en tiempo real.
  * Juegos numéricos (generación aleatoria con `Math.random()`).
  * Simulación de sistemas reales: cálculo de nóminas con pluses, venta de entradas con cupo máximo, control de turnos y trabajadores.

## 🚀 Cómo clonar y ejecutar los ejercicios

### 1. Clonar el repositorio
```bash
git clone https://github.com/Bcoast84/DAW_Programacion.git
cd DAW_Programacion
```

### 2. Compilar y ejecutar desde terminal (ejemplo):
```bash
# Compilar un ejercicio específico
javac Trimestre1/tarea3_b/Ejercicio1_14.java

# Ejecutar el archivo compilado
java -cp Trimestre1/tarea3_b Ejercicio1_14
```

### 3. Ejecutar desde Apache NetBeans / VS Code
* Abre el proyecto o la carpeta raíz desde el IDE.
* Navega por los paquetes en la estructura de árbol (`Trimestre1.tarea...`).
* Haz clic derecho sobre el archivo `.java` que desees probar y selecciona **Run File** (`Shift + F6` en NetBeans).
